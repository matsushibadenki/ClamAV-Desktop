# ClamAV Desktop 0.3.1

macOS / Apple Silicon（aarch64）向けの更新機構修正版。

## 日本語

- macOS WebViewで表示されない`window.confirm`をアプリ内の更新確認ダイアログへ置き換えました。更新先バージョンを表示し、明示的に確認するまでインストールを開始しません。
- 更新アーカイブからAppleDouble（`._`）メタデータを除外し、Tauriが展開できる構造を配布前に検証します。
- 0.3.0のworker切替・予約検査・3言語対応を含みます。

**0.2.0 / 0.3.0からの移行:** 旧版の確認UIは更新先だけでは修復できないため、初回はこのリリースのDMGを開き、アプリを終了してからアプリ本体を置き換えてください。アプリデータ保存先は削除しないでください。更新公開鍵は維持しています。

## English

- Replaced the unavailable native `window.confirm` path with an in-app confirmation dialog showing the target version. Installation starts only after explicit confirmation.
- Removed AppleDouble (`._`) metadata from updater archives and added a raw-entry check before distribution.
- Includes the worker handoff, scheduled scans and three-language support from 0.3.0.

**Migrating from 0.2.0 / 0.3.0:** The confirmation UI in an already-installed client cannot be repaired by a new update payload. Install this DMG manually once: quit the app, replace the app bundle, and retain the application-data directory. The updater public key is unchanged.

## 简体中文

- 将 macOS WebView 中无法显示的 `window.confirm` 替换为应用内确认对话框，显示目标版本，并仅在明确确认后开始安装。
- 从更新归档中移除 AppleDouble（`._`）元数据，并在发布前检查实际归档条目。
- 包含 0.3.0 的后台切换、定时扫描及三语言支持。

**从 0.2.0 / 0.3.0 迁移：** 新版更新包无法修复已安装旧版的确认界面。首次请手动安装本版 DMG：退出应用、替换应用本体，并保留应用数据目录。更新公钥保持不变。
