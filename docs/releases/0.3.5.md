# ClamAV Desktop 0.3.5

## 日本語

- 診断JSONにworkerの起動記録を追加しました。起動ごとの識別子、PID、準備完了時刻を最大16件保存します。
- メイン画面と浮動ログを独立したTauri WebviewWindowとして作成します。

## English

- Diagnostic exports include up to 16 worker readiness records with an instance ID, PID and readiness time.
- The main view and floating activity log open in independent Tauri WebviewWindows.

## 简体中文

- 诊断导出包含最多 16 条后台进程就绪记录，包括实例标识、PID 和就绪时间。
- 主界面和浮动活动日志使用独立的 Tauri WebviewWindow。
