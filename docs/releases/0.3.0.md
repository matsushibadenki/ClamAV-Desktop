# ClamAV Desktop 0.3.0

**既知の問題:** アプリ内更新の確認UIと更新アーカイブの展開に問題が見つかりました。修正版を準備中です。現行のDMGは署名・公証済みですが、この版からのアプリ内更新は利用できません。

**Known issue:** In-app updating is blocked by the confirmation UI and archive metadata. A fix is being prepared. The signed/notarized DMG remains available, but this version cannot initiate in-app upgrades.

**已知问题：** 应用内更新的确认界面及归档元数据存在问题，修复版正在准备中。DMG 已签名及公证，但此版本无法启动应用内更新。

macOS / Apple Silicon（aarch64）向け。

## 日本語

- GUIとworkerの所有権切替に対応。検査・定義更新・隔離・復元・診断出力をworkerが継続します。
- 起動済みworkerで毎日の予約検査と定義自動更新を実行します。日付別の永続記録で重複を防ぎ、1時間の開始枠・時計変更・中断復旧を処理します。
- 設定に保存済み予約の状態と見送り理由を追加しました。英語・日本語・简体中文に対応します。
- 0.2.0と同じ更新公開鍵・配信URLを使用し、署名されたバージョンを検証します。

ログイン時の自動起動登録は未対応です。worker接続中のアプリ更新はできないため、GUIへ戻してから更新してください。Intel・macOS 12実機、実スリープ復帰、外付け切断の確認は継続中です。

## English

- Switch live ownership between the app and its worker. Scans, definitions updates, quarantine, restore and diagnostic exports can continue in the worker.
- An already-running worker now performs daily scheduled quick scans and automatic definitions updates. Durable daily records prevent duplicate runs; a one-hour start window, clock changes and interrupted runs are handled explicitly.
- Settings displays saved schedule status and reasons in English, Japanese and Simplified Chinese.
- Updates remain compatible with the public key and feed used by 0.2.0, including signed-version verification.

Login startup registration is not included. Return to GUI ownership before updating the application. Intel/macOS 12 hardware, real sleep/wake and external-device removal remain unverified.
