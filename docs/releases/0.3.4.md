# ClamAV Desktop 0.3.4

macOS / Apple Silicon (aarch64)

## 日本語

- LaunchAgentが未読み込みのとき、移動済みアプリの登録修復・登録解除が失敗する問題を修正しました。
- macOSの終了コード3を扱い、GUIドメインの正常応答と対象サービスの不在を別々に確認できた場合のみ処理を続行します。状態が不明な場合は登録を保持します。

**0.3.2 / 0.3.3から:** アプリ内更新を利用できます。ログイン起動を登録済みの場合は解除し、処理完了後にGUI内実行へ戻してから更新してください。0.3.3で未読み込み登録の解除に失敗する場合は、登録が一致する配置で「再接続・再起動」を実行し、その後解除してください。

**0.3.1以前から:** 更新署名鍵の移行により、初回はDMGで手動導入してください。アプリを終了して本体を置き換え、データ保存先は保持してください。

## English

- Fixed moved-app registration repair and removal when the LaunchAgent is unloaded.
- Handles macOS exit code 3 only after independently confirming a responsive GUI domain and an absent target service. Uncertain status preserves the registration.

**From 0.3.2 / 0.3.3:** Use the in-app update. Remove login-service registration and return to local GUI mode after operations finish. If 0.3.3 cannot remove an unloaded registration, use reconnect/restart at the matching app location first, then remove it.

**From 0.3.1 or earlier:** Install the DMG manually once for the updater key migration. Quit the app, replace its bundle, and retain application data.

## 简体中文

- 修复 LaunchAgent 未加载时，移动后的应用注册修复及注销失败的问题。
- 仅在分别确认 GUI 域正常响应且目标服务不存在后，处理 macOS 退出码 3 并继续操作。状态不明确时保留原注册。

**从 0.3.2 / 0.3.3 更新：** 可使用应用内更新。请等待任务结束、注销登录服务并返回 GUI 本地模式。若 0.3.3 无法注销未加载的注册，请先在注册匹配的应用位置执行重新连接／重启，再注销。

**从 0.3.1 或更早版本迁移：** 因更新签名密钥迁移，首次请手动安装 DMG。退出应用、替换应用本体，并保留应用数据。
