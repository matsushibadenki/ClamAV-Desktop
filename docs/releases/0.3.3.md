# ClamAV Desktop 0.3.3

macOS / Apple Silicon (aarch64)

## 日本語

- 有効なDeveloper ID署名を誤って拒否する問題を修正し、LaunchAgentの登録・解除を利用できるようにしました。
- OSのバックグラウンド許可変更後、フォーカス復帰とworkerの切断・再接続に合わせて許可・読み込み表示を更新します。
- 登録・解除、GUI終了後の継続、許可オフ／オン、正常workerへの再接続、未読み込みworkerの復旧を実機検証しました。

**0.3.2から:** アプリ内の更新確認から更新できます。workerを使用中の場合は処理完了後にGUIへ戻し、ログイン起動を登録済みの場合は登録解除してから更新してください。

**0.3.1以前から:** 更新署名鍵を切り替えたため、初回は本リリースのDMGで手動移行してください。アプリを終了して本体を置き換え、アプリデータ保存先は保持してください。

## English

- Fixed rejection of valid Developer ID signatures so LaunchAgent registration and removal can proceed.
- Refreshes OS permission and loading status on native focus and worker connection changes after background permission changes.
- Verified live registration/removal, worker continuity after GUI quit, permission off/on, healthy-worker reconnection and unloaded-worker recovery.

**From 0.3.2:** Use the in-app update check. Wait for operations to finish and return from worker mode to GUI mode; remove any login-service registration before updating.

**From 0.3.1 or earlier:** The updater signing key has changed. Install this DMG manually once: quit the app, replace the app bundle, and retain the application-data directory.

## 简体中文

- 修复错误拒绝有效 Developer ID 签名的问题，支持正常注册及注销 LaunchAgent。
- 系统后台许可变更后，通过原生窗口焦点及后台进程连接变化刷新许可和加载状态。
- 已实机验证注册及注销、GUI 退出后的持续运行、许可关闭及恢复、正常进程重连与未加载进程恢复。

**从 0.3.2 更新：** 可使用应用内更新检查。请等待任务结束并从后台模式返回 GUI；若已注册登录服务，请先注销再更新。

**从 0.3.1 或更早版本迁移：** 更新签名密钥已更换。首次请手动安装本版 DMG：退出应用、替换应用本体，并保留应用数据目录。
